
# 👥 HR & Employee Attrition Intelligence Platform

An enterprise-grade workforce analytics platform designed to diagnose employee turnover drivers, analyze salary distributions across departments, and predict flight risk probabilities in real time using Machine Learning.

---

## 🌐 Live Application
Access the deployed Streamlit dashboard here:  
👉 **[Launch Live HR Intelligence OS](https://hrplatform.streamlit.app/
)**

---

## ⚡ Key Features

* **Executive Control Panel**: High-level KPIs including total headcount, overall attrition rate, average salary, and average tenure.
* **Workforce Diagnostics**: Interactive department-wise attrition bar charts and salary distribution box plots.
* **Behavioral Drivers**: Evaluates overtime impact and work-life balance scores on attrition rates.
* **Flight Risk Simulator**: Real-time interactive model evaluating flight risk probabilities based on custom employee attributes.
